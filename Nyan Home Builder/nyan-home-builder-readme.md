# Nyan Home Builder

เกมสร้างบ้านแบบ The Sims 4 ที่รันในเบราว์เซอร์ล้วน ๆ — ไม่ต้องติดตั้งอะไร ไม่ต้องมีเซิร์ฟเวอร์ เปิดไฟล์ `nyan-home-builder.html` ไฟล์เดียวก็เล่นได้ทันที

**เวอร์ชัน:** v0.36.0
**ไฟล์:** `nyan-home-builder.html` (ไฟล์เดียว จบในตัว ประมาณ 1.0 MB รวมทั้ง 3D engine และตัวแปลงไฟล์ export ฝังไว้ในไฟล์แล้ว — **ออฟไลน์ได้ 100% ทั้งการเล่นและการดาวน์โหลดโมเดล .glb** ยกเว้นฟอนต์ตกแต่งหน้าเว็บที่โหลดจาก Google Fonts ถ้าออฟไลน์จะใช้ฟอนต์สำรองของเครื่องแทน หน้าตายังปกติดี)

---

## เปิดเล่นยังไง

ดับเบิลคลิกไฟล์ `nyan-home-builder.html` เพื่อเปิดด้วยเบราว์เซอร์ (แนะนำ Chrome, Edge, หรือ Safari รุ่นใหม่ — ต้องรองรับ WebGL) แค่นั้นจบ ไม่มีขั้นตอนติดตั้งเพิ่มเติม

งานที่สร้างจะ **บันทึกอัตโนมัติลง localStorage ของเบราว์เซอร์เครื่องนั้น** ปิดแท็บแล้วเปิดใหม่บ้านยังอยู่ครบ (แต่ผูกกับเบราว์เซอร์ + เครื่องเดิมเท่านั้น ยังไม่ใช่เซฟบนคลาวด์ — ถ้าเปลี่ยนเครื่องหรือเปลี่ยนเบราว์เซอร์ต้องเริ่มใหม่)

## ภาพรวม

เกมมีสองโหมดสลับกันได้ตลอดเวลา:

- **🔨 โหมดสร้าง (Build Mode)** — ลากพื้น ลากผนัง วางรั้ว มุงหลังคา เจาะประตู/หน้าต่าง แขวนของบนผนัง ทาสี วางเฟอร์นิเจอร์ วางของตกแต่งบนโต๊ะ
- **▶ โหมดเล่น (Play Mode)** — ปิดเครื่องมือสร้างทั้งหมด เหลือแค่สไลเดอร์เลื่อนเวลา ดูบ้านตั้งแต่เช้าจรดกลางคืน แสงและเงาเปลี่ยนไปตามเวลาจริง

| 🏺 ของบนโต๊ะ | แจกัน กองหนังสือ ชามผลไม้ เทียนหอม — วางบนโต๊ะหรือพื้นก็ได้ |

## ระบบหลังคา 🏠

### สร้างด้วยการลาก

เลือกเครื่องมือ **🏠 หลังคา** แล้ว **ลากคลุมพื้นที่ห้องที่จะมุง** (ลากบนช่องพื้นได้เลย) ปล่อยเมาส์ = ได้หลังคาขนาดพอดีวางบนหัวผนังทันที

ที่ลากแล้วได้พอดีเพราะกริดเป็น 1 เมตร และผนังตั้งอยู่**บนเส้นกริด** ช่องพื้นของห้องจึงกินระยะจากแนวผนังถึงแนวผนังพอดีอยู่แล้ว — ลากคลุมกี่ช่อง ก็คือกว้าง-ลึกกี่เมตรตรง ๆ และเพราะไม่ได้ผูกกับผนัง จะลากคลุมครึ่งห้อง คลุมระเบียง หรือลากกลางสนามเป็นโรงจอดรถก็ได้ มุงซ้อนหลายผืนได้ เช่น ตัวบ้านผืนหนึ่ง ระเบียงอีกผืน

| มีให้เลือก | รายละเอียด |
|---|---|
| 🏠 หลังคาจั่ว | สองแผ่นลาดประกบสันบนตรงกลาง · เปลี่ยนสีแยกได้ 3 จุด (กระเบื้อง / สันบน / ผนังหน้าจั่ว) |
| 🔺 หลังคาปั้นหยา | ลาดทั้ง 4 ด้านชนกันเป็นยอดแหลม · เปลี่ยนสีแยกได้ 2 จุด (กระเบื้อง / ลูกแก้วยอด) |
| ความชัน | เตี้ย / ปกติ / ชัน — คิดความสูงสันให้เองเป็นสัดส่วนของช่วงที่ต้องพาด ห้องยิ่งกว้างสันยิ่งสูงตาม ("ปกติ" ราว 30° องศาหลังคากระเบื้องทั่วไป) |

**หลังคาจั่วหันสันไปตามด้านที่ยาวกว่าให้เอง** ตามหลักที่สันหลังคาต้องวางตามด้านยาวของอาคาร (ถ้าพื้นที่ที่ลากกว้างกว่าลึก ระบบหมุนชิ้นให้ 90° เอง) ส่วนปั้นหยาเป็นทรงพีระมิดไม่มีสันให้หัน

### ปรับต่อด้วยการลากหัวจับในฉาก

คลิกเลือกหลังคาด้วยเครื่องมือ **เลือก** จะเห็นหัวจับสีขาวโผล่มาบนตัวหลังคา ลากได้เลยในฉาก:

- **ลูกศร 4 ทิศรอบแนวชายคา** (ด้านละอัน) — ลากออก/เข้าเพื่อขยายหรือหดด้านนั้น **เฉพาะด้านของตัวเอง** ด้านตรงข้ามปักอยู่กับที่ ตัวหลังคาเลื่อนจุดกึ่งกลางตามให้เองครึ่งหนึ่งของระยะที่เพิ่ม (ไม่งั้นหลังคาจะเดินหนีออกจากบ้านทุกครั้งที่ลาก)
- **ลูกบอล 2 ลูกบนผืนหลังคา** — ลากขึ้น-ลงเพื่อปรับความสูงสัน

เปิด Snap อยู่ ขอบจะลงล็อกทีละ 0.5 ม. ซึ่งเป็นระยะที่ผนังตั้งอยู่ · ปิด Snap ละเอียดทีละ 5 ซม. · หัวจับคงขนาดบนจอเสมอไม่ว่าซูมเข้าออกแค่ไหน และคลิกทะลุตัวหลังคาได้

### หรือใส่ตัวเลขตรง ๆ ที่แผงขวา

เลือกหลังคาแล้วแผงขวาจะมีสไลเดอร์ **ความกว้าง / ความลึก / ความชัน-ยอด** แยกอิสระจากกัน (ไม่ใช่สไลเดอร์ "ขนาด" ตัวเดียวแบบเฟอร์นิเจอร์อื่น) บวก **ระดับขึ้น-ลง** ช่วง −3.00 ถึง +3.00 ม. โดย **0.00 = ชายคาวางบนหัวผนังพอดี** ลากไปทางลบเพื่อกดหลังคาลงต่ำกว่านั้นได้ (เผื่อระเบียง ผนังครึ่ง แนวรั้ว หรืออยากได้ทรงชายคาคลุมต่ำ)

ตัวเลขในแผงกับหัวจับในฉากเขียนค่าเดียวกัน ใช้สลับกันได้ตลอด ลากหัวจับแล้วตัวเลขวิ่งตามแบบเรียลไทม์

> หลังคาที่สร้างแล้วเป็น "ชิ้นวาง" ธรรมดาเหมือนเฟอร์นิเจอร์ทุกอย่าง — ลากย้าย หมุน (↺↻ หรือคีย์ R) เปลี่ยนสีทีละชิ้นส่วน ลบ ย้อน และ export .glb ได้ครบ

## รายละเอียดที่ทำให้เล่นลื่นขึ้น

- **Snap สองระดับ** — เปิดอยู่: ล็อกกับเส้นกริดเสมอ หมุนทีละ 45° (แบบ The Sims) · ปิดอยู่: วางอิสระทุกจุด หมุนละเอียดทีละ 7.5°
- **ผนังพับได้ 3 ระดับ** (เต็ม/ครึ่ง/ซ่อน) แก้ปัญหาผนังบังมุมมองตอนจัดของข้างใน
- **เปลี่ยนสีเฟอร์นิเจอร์ได้ทีละชิ้นส่วน** ไม่ใช่ทั้งตัว — ระบบไล่ดูเองว่าโมเดลมีกี่สี แล้วให้เลือกทีละส่วน
- **หัวจับลากปรับขนาดหลังคาในฉาก** ไม่ต้องเลื่อนสไลเดอร์แล้วเงยหน้าดูว่าพอดีหรือยัง
- **แสงกลางวัน-กลางคืนแบบไดโอรามา** ปรับความอบอุ่น ความสว่างรวม และความเข้มเงาได้อิสระ ซ้อนทับกับนาฬิกาเวลาของวัน
- **ของบนโต๊ะขยับตามโต๊ะเอง** ผ่านโครงสร้าง parent-child ของฉาก 3D ย้าย/หมุน/ขยายโต๊ะแล้วของบนโต๊ะตามไปฟรี ๆ

## ยังไม่ทำ

บ้านหลายชั้น บันได ผนังโค้ง สระว่ายน้ำ และระบบเดินของตัวละคร (pathfinding) — ทั้งหมดนี้เป็นงานคนละก้อนที่ยังไม่ได้เริ่ม

ฝั่งหลังคาที่ยังไม่มี: ระบบอ่านรูปร่างผนังแล้วฟิตหลังคาให้เองอัตโนมัติ (ตอนนี้ใช้วิธีลากคลุมพื้นที่เอาเอง ซึ่งครอบคลุมกรณีใช้งานจริงเกือบหมดแล้ว) และหลังคาทรงอื่น เช่น เพิงหมาแหงน โดม หรือหลังคาหักมุมหลายระดับในชิ้นเดียว

## เบื้องหลังทางเทคนิค (สำหรับคนอยากรู้)

สร้างด้วย **three.js r128** (ฝังไว้ในไฟล์ HTML โดยตรง พร้อมตัวแปลงไฟล์ GLTFExporter ไม่ต้องโหลดจาก CDN ภายนอกเลย) โมเดล 3D ทุกชิ้นปั้นขึ้นด้วยโค้ดล้วน ๆ (ไม่มีไฟล์โมเดลแยก) ลายไม้/อิฐ/ผ้าวาดด้วย Canvas API ตอนรันไทม์แล้วแปะเป็น texture งานทั้งหมดเก็บเป็น JSON ลง `localStorage` ของเบราว์เซอร์

หลังคาเป็นชิ้นที่**สร้างเรขาคณิตใหม่ทุกครั้งที่ปรับขนาด** แทนการสเกลรูปทรงเดิม เพราะพิกัดของหลังคาฝังความสูงผนัง (2.7 ม.) ไว้ในตัวเพื่อให้ชายคาลงตรงหัวผนังพอดี ถ้าใช้การสเกลค่านั้นจะถูกคูณตามไปด้วยแล้วหลังคาจะลอย — สร้างใหม่ที่ขนาดจริงจึงเป็นวิธีเดียวที่ชายคาลงพอดีทุกขนาด

โมเดลทุกชิ้นในเกม export เป็นไฟล์ `.glb` (glTF binary) ได้ — พกรูปทรง วัสดุ และลายที่วาดไว้ไปด้วยในไฟล์เดียว เปิดต่อได้ใน Blender, Godot, Unity หรือโปรเจกต์ three.js อื่น ๆ โดยสเกลเป็นเมตรตรงตามเกมอยู่แล้ว

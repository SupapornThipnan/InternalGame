## เปิดยังไง

เปิด `index.html` ด้วยเบราว์เซอร์ได้เลย ไม่ต้องมีเซิร์ฟเวอร์
(จงใจเขียนเป็นไฟล์เดียว ไม่ใช้ ES module เพื่อให้ `file://` ทำงานได้ — แก้ไฟล์แล้วกด F5 เห็นผลทันที)

```
open index.html
```

## ค่าที่กำลังจูน

อยู่รวมกันที่บล็อก `tuning knobs` ใกล้ต้นไฟล์

| ค่า | ตอนนี้ | ความหมาย |
|---|---|---|
| `SNAP_RADIUS` | `1.55` | ระยะดูดเข้าล็อก หน่วยโลก (ร้านกว้าง 6.6) |
| `LIFT` | `0.90` | ยกชิ้นที่ถืออยู่ให้พ้นนิ้ว |
| `TRAY_SCALE` | `0.46` | ขนาดชิ้นตอนอยู่ในถาด |
| `SNAP_TIME` | `0.20` | เวลาแอนิเมชันตอนเข้าล็อก |
| `BACK_TIME` | `0.30` | เวลาลอยกลับถาดตอนวางพลาด |

ทั้งหมดวัดเป็นหน่วยโลก ไม่ใช่พิกเซล — ทำได้เพราะกล้องเป็นออร์โธกราฟิก
ถ้าเปลี่ยนไปเพอร์สเปกทีฟเมื่อไหร่ ค่าพวกนี้จะต้องแปลงผ่านระยะกล้องทุกเฟรม

## กล้อง

- ออร์โธกราฟิก ล็อก 8 ทิศ (ปล่อยนิ้วแล้วไหลเข้าทิศใกล้สุด)
- มุมก้มดึงกลับเข้าไอโซเมตริกแท้ `atan(1/√2)` = 35.264° เสมอ
- สถานะกล้องเก็บเป็นมุม (`azim`, `elev`, `dist`) ไม่ใช่ตำแหน่ง xyz
  ทำให้เซฟมุมที่ผู้เล่นชอบได้ และสลับเลนส์ได้ด้วยสวิตช์เดียว

## เสียง

สังเคราะห์สดด้วย WebAudio ทั้งหมด ไม่มีไฟล์เสียงสักไฟล์ — จูนความถี่กับ decay ได้ในโค้ดเลย
`sfxClack` คือเสียงหลักของเกม (ชิ้นเข้าล็อก) แก้ตรงนั้นก่อนถ้าจะจูนความรู้สึก

## ยังไม่ได้ทำ (ไป M1)

- แยกชุดโมเดลออกเป็น JSON แทนอาเรย์ `SPEC` ในไฟล์
- ขั้นตอนปลดชิ้นออกจากแผ่น (punch-out)
- เซฟความคืบหน้ากลางคัน
- ระบบตกแต่งและเปลี่ยนโทนสี
- อาร์ตจริง (ตอนนี้เป็นกล่องล้วน ๆ โดยตั้งใจ)

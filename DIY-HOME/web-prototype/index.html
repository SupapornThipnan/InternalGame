Snap tolerance

ระยะดูดเข้าล็อก

วัดจากจุดกึ่งกลางชิ้นถึงจุดเสียบ ในหน่วยโลก ไม่ใช่พิกเซล — ค่าเดียวใช้ได้ทุกมุมทุกระดับซูม เพราะกล้องเป็นออร์โธ

Finger offset

LIFT = 0.9 หน่วย + เอียงตามการลาก

ที่ยังไม่ได้ทำใน M0

ตั้งใจเว้นไว้ ไปทำใน M1

  • ระบบขับด้วยข้อมูล — ตอนนี้ชุดโมเดลยังเป็นอาเรย์ SPEC ในไฟล์เดียว M1 จะแยกเป็น JSON ต่อหนึ่งชุด แล้วโหลดเข้ามา
  • ปลดชิ้นจากแผ่น — ตอนนี้ชิ้นส่วนโผล่ที่ถาดเลย ยังไม่มีขั้นตอนกดดันออกจากรอยปรุ
  • เซฟกลางคัน — ปิดแท็บแล้วเริ่มใหม่ ยังไม่เก็บความคืบหน้า
  • ตกแต่งและเปลี่ยนโทนสี — ยังไม่มี palette swap และการวางของประดับอิสระ
  • อาร์ตจริง — ทุกชิ้นเป็นกล่องกับทรงกระบอกล้วน ๆ จงใจ เพื่อให้ตัดสินความรู้สึกมือโดยไม่ถูกอาร์ตหลอกตา

// เพิ่มของประดับจากชุดสวนเข้าไปในสเตจ "ของประดับ" ของร้านไหนก็ได้
['กระถางเลมอน', pottedPlant('lemon'), [3.4, 0, 1.6], [0, 0.3, 0], 'ของประดับ'],
['ม้านั่งสวน',   bench('wood'),        [-3.6, 0, 2.2], [0, -0.4, 0], 'ของประดับ'],
['โคมหินญี่ปุ่น', lantern('stone'),     [4.2, 0, 0.4],  [0, 0, 0], 'ของประดับ']
  • ทุกชิ้นวาง pivot ไว้ที่ฐาน (y = 0 คือจุดที่ของแตะพื้น) ตามกฎ authoring ใน Outline — เสียบลง socket แล้วไม่จม ไม่ลอย
  • วัสดุใช้ร่วมกันผ่าน cache — สีเดียวกันใช้ material ตัวเดียวทั้งชีต ลดภาระ GPU ตอนมีของเยอะ ๆ พร้อมกันในหมู่บ้าน
  • เงาเป็นแผ่นวงกลมใต้ของ ไม่ได้ใช้ shadow map — เทคนิคเดียวกับที่ห้องไอโซเมตริกใน reference ใช้ ทำให้วางของ 81 ชิ้นพร้อมกันได้โดยเฟรมเรตไม่ตก
  • โคมและตะเกียงมี material แยกของตัวเอง เลยสั่งให้เรืองแสงตอนกลางคืนได้ทีละดวง (ลองกดปุ่ม "กลางคืน" ดูครับ)

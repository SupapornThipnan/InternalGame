# 3D Model TEST

หน้าโชว์เคสโมเดล 3D ที่รันในเบราว์เซอร์ล้วน ๆ — ใช้เป็น "ห้องทดลอง" ปั้น/ปรับแต่ง/ตรวจสอบพร็อพแต่ละชิ้นก่อนเอาไปใส่ในเกม **Nyan Home Builder** ไม่ใช่ตัวเกมสร้างบ้านเอง แต่เป็นเครื่องมือคู่กันที่ใช้ดูโมเดลทีละตัวแบบใกล้ชิด หมุนดูได้รอบทิศ และดาวน์โหลดออกไปใช้ที่อื่นได้

เปิดไฟล์ `nyan-3d-model-test.html` ไฟล์เดียวก็ใช้งานได้ทันที ไม่ต้องติดตั้งอะไร ไม่ต้องมีเซิร์ฟเวอร์

**ไฟล์:** `nyan-3d-model-test.html` (ไฟล์เดียว จบในตัว ประมาณ 740 KB รวม 3D engine และตัวแปลงไฟล์ export ฝังไว้ในไฟล์แล้ว — ไม่ต้องต่อเน็ตก็ใช้งานและดาวน์โหลดโมเดลได้ครบทุกฟีเจอร์)

## เปิดใช้งานยังไง

ดับเบิลคลิกไฟล์ `nyan-3d-model-test.html` เพื่อเปิดด้วยเบราว์เซอร์ (แนะนำ Chrome, Edge, หรือ Safari รุ่นใหม่ — ต้องรองรับ WebGL) แค่นั้นจบ

หน้านี้ไม่มีระบบเซฟ — เป็นห้องโชว์ล้วน ๆ ไม่มีอะไรให้แก้ไขหรือบันทึกระหว่างเล่น

## มีโมเดลอะไรให้ดูบ้าง

แถบด้านบนสลับดูได้ 7 ชิ้น:

| ไอคอน | โมเดล |
|---|---|
| 🛋 | โซฟาผ้าต่อสองที่นั่ง |
| 🪟 | หน้าต่างกลมกรอบไม้ |
| 🪵 | รั้วไม้ปลายแหลม |
| 🪑 | ม้านั่งไม้ |
| 🏮 | ตะเกียงน้ำมันโบราณ |
| 🌻 | ทานตะวันกระถาง |
| 🔥 | เตาอบพิซซ่าอิฐ (มีควันลอยจากปล่องด้วย) |

แต่ละชิ้นมีการ์ดอธิบายมุมซ้ายบน (กดปุ่มลูกศรเพื่อย่อ/ขยาย) เล่าเบื้องหลังการปั้น เช่น ทำไมถึงเลือกใช้เทคนิคนั้น ๆ แก้บั๊กอะไรไปบ้าง และแถบสีของวัสดุที่ใช้ในโมเดลนั้น

## ดาวน์โหลดโมเดลออกไปใช้ที่อื่น

มุมล่างมีสองปุ่ม:

- **⬇ .glb ตัวนี้** — ดาวน์โหลดเฉพาะโมเดลที่กำลังดูอยู่
- **⬇ ทั้งชุด** — ดาวน์โหลดทั้ง 7 ชิ้นรวดเดียว

ไฟล์ที่ได้เป็น **glTF binary (.glb)** — มาตรฐานเปิดที่พกรูปทรง วัสดุ และลายผิว (ไม้/อิฐ/ผ้าที่วาดด้วย Canvas ตอนรันไทม์) ไปด้วยในไฟล์เดียว เปิดต่อได้ตรง ๆ ใน **Blender, Godot, Unity** (ผ่าน glTFast/UnityGLTF) หรือโปรเจกต์ three.js อื่น สเกลเป็นเมตรตรงตามที่ปั้นไว้ในเกม ไม่ต้องคูณขนาดเพิ่ม

> เมื่อเปิดไฟล์ HTML นี้ตรง ๆ (ไม่ได้อยู่ในหน้าเว็บที่มีข้อจำกัดเรื่องนามสกุลไฟล์) จะได้ไฟล์ `.glb` ออกมาตรง ๆ ไม่ต้องแตกซิป

## เบื้องหลังทางเทคนิค (สำหรับคนอยากรู้)

สร้างด้วย **three.js r128** โมเดลทุกชิ้นปั้นขึ้นด้วยโค้ดล้วน ๆ ไม่มีไฟล์โมเดลสำเร็จรูปจากที่อื่น อาศัยเทคนิคหลักสองอย่าง:

- **ExtrudeGeometry + bevel** สำหรับทุกชิ้นที่มีขอบมน — วาดเส้นขอบ 2D แล้วรีดขึ้นเป็น 3D พร้อมลบมุม ให้ขอบนุ่มเหมือนของจริงโดยไม่ต้องปั้นมือทีละหน้า
- **Canvas texture** สำหรับลายไม้/อิฐ/ลายผ้า — วาดลายด้วย JavaScript ตอนรันไทม์แล้วแปะเป็นผิว แทนการใช้ไฟล์ภาพแยก ทำให้ไฟล์เบาและลายยืด-หดพอดีกับขนาดจริงของแต่ละชิ้นเสมอ

โมเดลทุกตัวยังผ่านการ **ลดจำนวนโพลิกอน (poly reduction)** เพื่อให้เอาไปใช้ในเกมได้โดยไม่หนักเครื่อง เช่น โซฟาผ้าต่อลดจาก 9,384 เหลี่ยม เหลือ 4,728 เหลี่ยม (~50%) และหน้าต่างกลมลดไป ~45% โดยตรวจสอบด้วยการเรนเดอร์เทียบภาพก่อน-หลังทุกครั้ง เพื่อให้แน่ใจว่าหน้าตาไม่เปลี่ยนแม้เหลี่ยมจะน้อยลง

ตัวแปลงไฟล์ (GLTFExporter) เป็นสคริปต์แยกที่ฝังไว้ในไฟล์เดียวกันแล้ว จึงกด export ได้ทันทีโดยไม่ต้องรอโหลดจากอินเทอร์เน็ต

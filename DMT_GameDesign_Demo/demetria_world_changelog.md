## v1.9.0 — ระบบบันทึกเกม (Save / Load System) ✅ (ล่าสุด)
**ทำตาม `GAME_DESIGN.md` ข้อ 14 ครบทุกข้อย่อย (14.1–14.7) — ก่อนหน้านี้เล่นนานๆ แล้ว refresh ของหายหมด**

### ที่เก็บข้อมูล (14.1) + หลายสล็อต (14.2)
- ใช้ `localStorage` — ดัชนีสล็อต `demetria_saves_index` (array ของ `{id,name,day,money,savedAt}`) แยกจากข้อมูลเกมเต็ม `demetria_save_<id>` ต่อสล็อต เปิดหน้าลิสต์สล็อตได้เร็วโดยไม่ต้องโหลดทุกก้อน
- แผงเซฟ/โหลดใหม่ (ปุ่ม "💾 เซฟ/โหลด" แถบล่าง): ลิสต์สล็อตพร้อมชื่อ/Day/เงิน/เวลาเซฟล่าสุด · ▶️ เล่นต่อ · ✏️ เปลี่ยนชื่อแบบ inline (คลิกแล้วพิมพ์ในช่องได้เลย Enter/blur เพื่อยืนยัน) · 🗑️ ลบ (ต้องกดยืนยันใน popup ก่อนจริง) · ➕ เซฟใหม่ (เว้นชื่อว่างได้ ระบบตั้ง "เซฟ N" ให้อัตโนมัติ)

### ปุ่มเซฟมือ (14.3)
- 💾 บน HUD หลัก เข้าถึงได้ตลอดเวลา กดแล้วทับสล็อตปัจจุบันทันที + toast "💾 บันทึกแล้ว"
- ยังไม่เคยผูกสล็อตไหนเลย (เกมใหม่ยังไม่เคยเซฟ) → กดครั้งแรกถามชื่อก่อน 1 ครั้ง (ผ่าน confirm modal ที่มีช่องพิมพ์ในตัว) จากนั้นกดซ้ำทับสล็อตเดิมตลอด

### Autosave (14.4)
- checkbox "🔄 บันทึกอัตโนมัติ" ในแผงเซฟ/โหลด **ค่าเริ่มต้นเปิด**
- ทริกเกอร์ 2 จุด: (1) ทุกครั้งที่ `onNewDay()` ทำงาน (2) ทุก 3 นาทีจริงผ่าน `setInterval` — เป็น backup เผื่อเล่นวันเดียวยาวๆ
- ทับสล็อตปัจจุบันเสมอ ไม่สร้างสล็อตใหม่ ไม่มี toast กวนใจ — ไอคอน 💾 กระพริบเบาๆ ~1 วิ (CSS keyframe `saveFlash`) ให้รู้ว่าเซฟแล้วพอ
- ไม่มีสล็อตผูกอยู่ (เช่นเพิ่งลบสล็อตที่กำลังเล่น) → autosave เป็น no-op เงียบๆ ไม่ auto-สร้างสล็อตใหม่ให้เอง

### หน้าจอเข้าเกม (14.5)
- เปิดไฟล์ครั้งแรกไม่มีเซฟเลยใน `localStorage` → เข้าเกมใหม่ทันที สร้างสล็อต "เกมใหม่" อัตโนมัติ ไม่ต้องเลือกอะไรก่อน (กันงงตอนโหลดครั้งแรก)
- มีเซฟอยู่แล้ว (แม้แค่สล็อตเดียว) → โชว์หน้าจอเลือกเซฟเต็มจอ (`#entryScreen` z-index สูงสุด บล็อกทุกอย่างจนกว่าจะเลือก) ลิสต์สล็อตแบบเดียวกับแผงเซฟ/โหลด + ปุ่ม "🆕 เกมใหม่"
- โลกเกม (`genWorld`/`placeStages`/ตำแหน่งจุดวาร์ป-ช่าง-คลัง) ยังคง generate แบบ deterministic เหมือนเดิมก่อนหน้าจอนี้จะโชว์ด้วยซ้ำ ดังนั้นเลือกสล็อตไหนก็ได้โลกเดียวกันเป๊ะ ตำแหน่งของในเซฟตรงกับแมพเสมอ
- ระหว่างเล่น กด 💾 เปิดแผงเดิมได้ตลอด สลับสล็อต/ลบ/เปลี่ยนชื่อได้แม้กำลังเล่นอยู่ — สลับสล็อตทั้งที่มีความคืบหน้ายังไม่ได้เซฟ (`isDirty()` เทียบกับ snapshot ตอนเซฟ/โหลดล่าสุด) จะเตือน popup ก่อนเสมอ

### ข้อมูลที่บันทึก (14.6) — ตรงตารางเป๊ะ
**เซฟ:** `day`,`time` · `money`,`inv`,`bagSlots` · `stages[].{unlocked,planted,daysGrown,storage,storageTier}` ทุกด่าน (ฟิลด์อื่นอย่าง emoji/accent/recipes/prereq **ไม่เซฟ** โหลดจาก DEF สดทุกครั้ง) · `warehouse`,`warehouseTier` · `deliveryOn/deliveryPaidUntil/deliveryWarned` · `quests[]` (รวม `pinned`),`qSeq`,`nextQuestIn` · `player.x/y` · `unlockedZones` (แปลง Set→array ก่อน `JSON.stringify` เสมอ) · `zoom`,`showMainQuestHud`

**ไม่เซฟ** (คำนวณใหม่ได้/เป็น UI ชั่วคราว): `near*` ทุกตัว, `openPanel/openStage/openWarp/openShop/openWh`, `whQty`/`collectQty`, `nextId`, `speed`, `paused`, `cam`, `player.dir/anim`

### เวอร์ชันเซฟ (14.7)
- ทุกเซฟติด `saveVersion:1` — `applySave()` มี migration hook พร้อมรองรับตอนโครงสร้างเปลี่ยนในอนาคต (บูรณะ/NPC routine ตามที่ Roadmap วางแผนไว้) จะได้ไม่พังหรือของหายเงียบๆ ตอนโหลดเซฟเก่าเข้าเกมเวอร์ชันใหม่

### Export / Import
- Export: ดาวน์โหลดสล็อตปัจจุบันเป็น `.json` (`Blob` + `<a download>`) ตั้งชื่อไฟล์ตามชื่อสล็อต+วันในเกม
- Import: เลือกไฟล์ `.json` → validate `saveVersion` ตรงและ parse JSON ได้ก่อนเสมอ ผ่านแล้วสร้างเป็น**สล็อตใหม่** (ไม่ทับสล็อตปัจจุบัน) — ไฟล์เสีย/เวอร์ชั่นไม่ตรง → toast แจ้งเฉยๆ ไม่ throw ไม่พังทั้งหน้า

### เครื่องมือกลาง
- generic confirm modal (`openConfirm(title, bodyHtml, okLabel, onOk)`) — body รับ HTML อะไรก็ได้ ใช้เป็นทั้ง popup ยืนยัน (ลบสล็อต/เตือนสลับสล็อต) และ prompt พิมพ์ข้อความ (ถามชื่อสล็อตตอนเซฟ/สร้างใหม่ครั้งแรก) จุดเดียวจบ — **ไม่แตะ `window.confirm()`/`prompt()` ของเบราว์เซอร์เลย** ให้หน้าตาตรงธีมเกมเหมือน modal อื่นทุกอัน
- ผู้เล่นหยุดเดินและปุ่ม E ไม่ทะลุไปโลกเกมระหว่างเปิด confirm modal (`G.confirmOpen`) เหมือน modal อื่นๆ

### เทสที่รันแล้ว (node จำลอง localStorage + DOM — 57 assertion ผ่านหมด)
- บูตครั้งแรกไม่มีเซฟใน `localStorage` เลย → สร้างสล็อต "เกมใหม่" อัตโนมัติ ไม่ค้างหน้าเปล่า ✅ · มีเซฟอยู่แล้ว → โชว์หน้าเลือกเซฟ ไม่เข้าเกมตรงๆ ✅

## v1.3.0 — จุดวาร์ปข้ามโซน ✅
**แก้ปัญหาผู้เล่นเดินเยอะเกินไป — ดีไซน์คุยกับน้องโค่ (Cowork) ไว้แล้ว**

**ปัญหา:** เทสพบว่า 52% ของการปลดล็อคด่านติดกัน (32/62 transitions) สลับข้ามโซนไปมา แต่ละโซนห่างจากเมืองหลวง ~17-18 ช่อง (5+ วิ เดินทางเดียว) ทางแก้ที่เลือกคือเพิ่มจุดวาร์ป 5 จุด **ไม่แตะสมดุลเศรษฐกิจ/ลำดับปลดล็อคเดิมเลย**

> ⚠️ **แก้ทิศทางจากรอบแรก:** implement รอบแรกทำเป็นปุ่ม 🗺️ ที่แถบล่าง (คีย์ลัด M) เปิด side panel กดแล้ว teleport ทันที — พี่แยมตรวจแล้วให้แก้ เพราะเป็น "ปุ่มลัดที่กดได้จากทุกที่บนแมพ" ผิดกฎ `nearEnough()` ที่ใช้ทั้งเกม (ต้องเดินไปถึงก่อนถึงจะทำอะไรได้) รอบนี้เขียนใหม่ทั้งหมดให้จุดวาร์ปเป็น **วัตถุจริงในแมพ** ต้องเดินไปหาแล้วกด E เหมือนด่านทุกด่าน

- **ข้อมูล:** `WARP_POINTS` array แยกจาก `DEF`/`buildings` — 5 จุด `{zone, gx, gy, triggerId}` วางที่ "ปากทาง" ของแต่ละโซน คำนวณจาก `ZONES` anchor/radius จริง: 🌾ออก(32,17)→`farm_a`, 🏰กลาง(24,24 ใกล้ npc_bread)→`npc_bread`, ⛏️ตก(15,33)→`forest_cave`, ❄️เหนือ(16,16)→`forest_snow`, 🌋ใต้(33,33)→`animal_croc`
- **Placement:** พิกัดดิบข้างบนไม่รับประกันไม่ทับตึกที่ `placeStages()` วางไว้ — รีแฟกเตอร์ logic หาไทล์ว่างที่ใช้ตอนหาจุดสปอนผู้เล่น (`findSpotBeside`) ให้เป็นฟังก์ชันทั่วไป `findFreeTile(x0,y0)` รับพิกัดตรงๆ ใช้ snap ทั้งจุดสปอนผู้เล่น, จุดวาง `WARP_POINTS` ทั้ง 5, และจุดลงวาร์ป
- **State:** `G.unlockedZones` (Set) seed ด้วย `{'east'}` ตั้งแต่เริ่มเกม (farm_a unlocked:true อยู่แล้ว)
- **Trigger:** `checkZoneUnlock(s)` เรียกท้าย `doUnlock()` เช็คว่า stage ที่เพิ่งปลดตรงกับ `triggerId` ของ `WARP_POINTS` อันไหนไหม ถ้าใช่ → เพิ่มโซนเข้า `G.unlockedZones` + toast "🗺️ ค้นพบจุดวาร์ป [ทิศ] แล้ว!" — เรียกใน Dev Panel (`devUnlockNext`/`devUnlockStage`) ด้วยเพื่อทดสอบ flow เต็มได้โดยไม่ต้องเดินจริง
- **Render:** `drawWarpPoint()` วาดเป็นหินสลักในพาสเดียวกับ `drawBuilding()` (depth-sort ร่วมกับตึก/ผู้เล่นตามปกติ ไม่ทำแยก layer) — ล็อคอยู่ = หินเทาหม่น 🔒, ปลดล็อคแล้ว = เรืองแสงธีมสี `ZONE_META[zone].color` ตลอดเวลา (ไม่ใช่แค่กลางคืนแบบหน้าต่างตึก) ให้เห็นชัดว่าใช้งานได้ — ไม่ขึ้นทะเบียนใน `buildings{}` จึงไม่บล็อกการเดิน
- **Interact:** `findNearWarp()` คู่ขนานกับ `findNear()` เดิม กด E ใกล้จุดวาร์ปที่ปลดล็อคแล้วเปิด modal ใหม่ `#warpModal` (แยกจาก `#modal` เดิมที่ผูกกับ `G.openStage` กันชนกัน) โชว์รายชื่อโซนอื่นที่ปลดล็อคแล้ว (ไม่รวมโซนที่ยืนอยู่) เลือกแล้ววาร์ปทันที — จุดที่ยังล็อค กด E ได้แค่ toast บอกว่าต้องปลดล็อคด่านไหนก่อน ไม่เปิด modal เปล่า
- **กันโกง:** วาร์ปแก้แค่ `G.player.x/y` ไม่แตะ inventory/money/stage state ใดๆ — `nearEnough()` ของ `doPlant/doHarvest/doCraft/doUnlock/submitQuest` อ่านตำแหน่งผู้เล่นสดทุกครั้งอยู่แล้ว (ไม่มี cache) ทดสอบยืนยันด้วย node script จำลอง DOM แล้วว่ายังบังคับใช้ปกติ 100% หลังวาร์ป
- **กล้อง:** `render()` เดิม snap กล้องไปตำแหน่งผู้เล่นทุกเฟรมอยู่แล้ว (ไม่มี lerp/smoothing) วาร์ปจึงไม่มีอาการจอกระตุกหรือไถลข้ามแมพ — ไม่ต้องเพิ่มโค้ดจัดการกล้องเลย
- **เทสที่รันแล้ว (จำลอง DOM ด้วย node script, 36 assertions):** syntax check `new Function` ผ่าน ✅ · seed เริ่มเกมมีแค่ east ✅ · จุดวาร์ปทั้ง 5 ไม่ทับตึกและอยู่บนไทล์จริง ✅ · trigger ตรงตาราง (farm_a/npc_bread/forest_cave/forest_snow/animal_croc) ✅ · ปลดล็อค npc_bread → center โผล่พร้อม toast "ค้นพบจุดวาร์ป" ✅ · ยืนที่จุดวาร์ปตกที่ยังล็อค กด E → ไม่เปิด modal มีแค่ toast บอกเงื่อนไข ✅ · ปลดล็อค forest_cave → west ใช้ได้ → วาร์ปจากกลางไปตกสำเร็จ ยืนใกล้จุดวาร์ปจริง ไม่ติดตึก ✅ · วาร์ปไม่แตะ money/inventory ✅ · วาร์ปไปโซนที่ยังล็อค (north) ไม่ขยับผู้เล่นเลย ✅ · กด E ใกล้ตึกปกติ (farm_a) ยังเปิด `#modal` เดิมได้ถูกต้อง ไม่ชนกับ `#warpModal` ✅

## v1.0.0 — Isometric World Release ✅
**เกมไอโซเมตริกเดินได้จริงตัวแรก ต่อยอดจากดีไซน์ ECO System 63 ด่าน**

- **World Map**: สร้างแมพ 5 โซนตามเข็มทิศ (เมืองหลวงตรงกลาง / เหนือ=หิมะ / ออก=ฟาร์ม / ใต้=ลาวา / ตก=เหมืองแร่) ด้วย value noise ให้ขอบโซนเป็นธรรมชาติไม่กลมเป๊ะ พร้อมถนนเชื่อมเมืองหลวงออกไปทั้ง 4 ทิศ
- **วางด่านอัตโนมัติ**: ดึงข้อมูล 63 stage จาก `eco_demo.html` (ITEMS + DEF + zone) มาวางบนกริดตามโซนจริง ไม่ทับกัน ทุกด่านเดินถึงได้ (verify ด้วย flood-fill)
- **การเดิน**: ตัวละครเดิน WASD/ลูกศร ชนอาคารไม่ได้ (collision), กล้องตามตัวละครแบบ smooth
- **กลางวัน-กลางคืน**: ท้องฟ้าไล่สีตามเวลา, พื้นมืดลงตอนกลางคืน, หน้าต่างอาคารที่ปลดล็อคแล้วติดไฟเหลืองพร้อมแสงกองรอบๆ, ตัวละครถือโคมส่องทางตอนกลางคืน, ปุ่มปรับความเร็วเวลา 1x/3x/8x + pause
- **Inventory**: แผงคลังของ (กด I) แสดงไอเทมที่เก็บมาได้ทั้งหมด
- **Quest**: NPC ที่ปลดล็อคแล้วสุ่มออกเควสขอไอเทม (กด Q ดู) ปุ่มเควสเรืองทองเมื่อมีเควสที่ส่งได้ ส่งเควสได้ทั้งจากแผง Quest และจากในร้าน NPC โดยตรง
- **โต้ตอบด่าน** (กด E ใกล้อาคาร หรือคลิกอาคาร): ปลูก/รอ/เก็บเกี่ยวสำหรับ passive stage, คราฟตามสูตรสำหรับ craft stage, ดูเงื่อนไขปลดล็อคพร้อม cost breakdown
- **มินิแมพ**: มุมขวาบน หมุน 45° เป็นรูปเพชรพร้อมป้ายทิศ N/S/E/W, จุดชมพู=ตัวเรา, จุดทอง=อาคารปลดล็อคแล้ว, จุดเทา=ยังล็อค

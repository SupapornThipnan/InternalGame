## 1. ทำไมแยก + กลไกที่ใช้ได้เลยจากของเดิม

- **เหตุผล:** ตอนพอร์ต Unity แต่ละโซนโหลดเฉพาะตอนเข้าไป ไม่ต้องขึ้น asset ทั้ง 63 ด่าน
  พร้อมกัน เข้ากับสไตล์เกมอ้างอิง (Stardew แยกฉากฟาร์ม/เมือง/เหมืองคนละซีน)
- **วาร์ป (v1.3.0) กลายเป็นจุดโหลดฉากแทนแค่ขยับตำแหน่ง** — ไม่ต้องคิดกลไกใหม่
  ใช้ 5 จุดวาร์ปที่มีอยู่แล้วเป๊ะ (ดูตารางข้อ 3)
- **เวลาเกม (`G.time`/`G.day`) ไม่ต้องแก้อะไร** — พิสูจน์แล้วว่าไม่ผูกกับโซนที่มองอยู่
  (idle production ทำงานครบ 63 ด่านตลอดเวลาอยู่แล้ว) แค่ย้ายไปเป็น state กลางที่ไม่ถูก
  ทำลายตอนสลับฉาก (Unity: Singleton/DontDestroyOnLoad) — เงิน/กระเป๋า/คลัง/เควส/เซฟ
  ก็ย้ายไปอยู่ state กลางชุดเดียวกัน

> จะดูว่างผิดปกติทันทีที่เข้าไป

## 3. ปัญหาที่ต้องคิดต่อถ้าแยกแมพจริง — chain ปลดล็อคกระโดดข้ามโซนตลอด

ลำดับปลดล็อค (`DEF` array order = wave order) **ไม่ได้เรียงตามโซน** เลย ตัวอย่างช่วงต้นเกม:

```
farm_a(east) → forest_a(east) → animal_a(east) → npc_bread(center) → farm_b(east)
→ forest_b(east) → npc_soup(center) → npc_wood(center) → animal_b(east) → ...
→ forest_cave(west) → npc_iron(west) → npc_coffee(center) → ...
```

ตอนนี้ (แมพเดียว) ระบบนำทาง (`nextUnlockStage()` + เข็มทิศ) พาเดินข้ามโซนได้ในแมพ
เดียวกันเลย — **แต่ถ้าแยกเป็นคนละฉาก ด่านถัดไปที่ต้องปลดล็อคอาจอยู่คนละฉากกับที่ผู้เล่น
ยืนอยู่ตอนนี้** เข็มทิศจะชี้ไปทิศที่ "ไม่มีทางเดินตรงถึง" เพราะต้องวาร์ปออกจากฉากปัจจุบัน
ก่อน

**ต้องตัดสินใจ:** เข็มทิศ/HUD ควรบอกยังไงเมื่อด่านถัดไปอยู่คนละฉอง — บอกว่า "วาร์ปไปโซน
X ก่อน" แทนทิศทางเดิน หรือให้ warp point เรืองแสง/ไฮไลต์เป็นสัญญาณแทน — **ยังไม่ได้
ออกแบบจุดนี้**

## 4. คำถามที่ยังไม่ปิด (ต้องคุยต่อก่อน implement)

- [ ] **เดินข้ามโซนที่ขอบแมพได้เลยไหม หรือบังคับผ่านวาร์ปเท่านั้น** (คำถามเดิมที่ยังไม่ตอบ)
      ถ้าเดินออกขอบได้ ต้องออกแบบจุดต่อขอบแมพให้ตรงกัน (เช่น ขอบตะวันออกของเมืองหลวง
      ต้องต่อกับขอบตะวันตกของโซนออกพอดี) — งานเพิ่มเยอะกว่าบังคับวาร์ปอย่างเดียวมาก
- [ ] **เข็มทิศ/นำทางข้ามฉาก** เมื่อด่านถัดไปอยู่คนละแมพ (ข้อ 3 ด้านบน)
- [ ] **Wave 12 — North** ควรทำก่อนแยกแมพจริงไหม (กันฉากเหนือดูว่างเปล่าตั้งแต่วันแรก
      ที่แยก)
- [ ] ยืนยันว่าจะยึด 5 โซนเดิมเป๊ะ (ไม่ขยับด่านข้ามโซน) — ถ้าอยากจัดสมดุลใหม่ (เช่น
      ย้ายบางด่านจาก east ไป north) ต้องทำก่อนแยกแมพ เพราะ `zone` field ผูกกับ world-gen
      เดิมอยู่

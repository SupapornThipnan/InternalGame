# Demetria Spirit — ข้อตกลงระบบเฟอร์นิเจอร์และ NPC

วันที่ยืนยัน: 22 กันยายน 2026  
สถานะ: พี่แยมยืนยันดีไซน์แล้ว ยังไม่ใช่รายงานว่า implement เสร็จ  
บันทึกโดย: น้องโค่

เอกสารนี้บันทึกข้อตกลงจากการสนทนาเพิ่มเติมจาก GAME_DESIGN.md โดยเฉพาะระบบบูรณะ การวางเฟอร์ และการใช้บริการ NPC เป็นบันทึกแยก ยังไม่ได้แก้เอกสารต้นฉบับในโฟลเดอร์ GameDesign

## 1. เฟอร์นิเจอร์และมินิเกมบูรณะ

- เฟอร์เฉพาะด่านแบบบังคับ: ต้องมีและวางครบตามเงื่อนไขด่าน เพื่อผ่านการบูรณะ
- เฟอร์เสริมแบบไม่บังคับ: ไม่จำเป็นต้องมี ผู้เล่นเลือกวางตามความชอบ
- เฟอร์เชื่อมกับมินิเกมบูรณะ: เล่นมินิเกมหมุนภาพให้ตรงเพื่อปลดล็อคของใหม่
- ผู้เล่นเลือกตำแหน่งและหมุนเฟอร์ได้อย่างอิสระภายใต้ข้อห้ามด้านจุดเกิด ทางออก และตำแหน่งตัวละคร
- เฟอร์เสริมเพิ่มกิจกรรมและบรรยากาศของ NPC โดยไม่กำหนดโบนัสการผลิตจากการตกแต่ง

## 2. การใช้บริการภายในด่าน

- ผู้เล่นใช้บริการคราฟผ่าน UI เมื่ออยู่ในด่าน ไม่จำเป็นต้องเดินถึงตัว NPC
- การที่ NPC เดินถึงเฟอร์หรือไม่ ไม่ขัดขวางการคราฟผ่าน UI โดยยังคงเงื่อนไขบริการอื่น เช่น เวลาเปิดร้านและวัตถุดิบ
- การเข้าถึงบริการจึงแยกจากการเดินไปเล่นแอคชั่นของ NPC

## 3. NPC เดินไปทำกิจกรรมตามเฟอร์

- NPC ใช้ pathfinding ไปยังจุดใช้งานของเฟอร์ที่เข้าถึงได้
- เฟอร์แต่ละชนิดกำหนดจุดและทิศทางใช้งาน เช่น หน้าเก้าอี้หรือช่องยืนหน้าโต๊ะ จุดนี้หมุนตามเฟอร์
- ตอนจัดวาง แสดงช่องใช้งานให้ผู้เล่นเห็นว่าควรเว้นพื้นที่ตรงไหน
- มีเฟอร์และเดินถึง: NPC เลือกไปทำกิจกรรมนั้นได้
- มีเฟอร์แต่ทางถูกปิด: NPC ข้ามกิจกรรมนั้น แล้วเลือกกิจกรรมอื่น
- ไม่มีเฟอร์เสริม: ไม่มีกิจกรรมที่ต้องใช้เฟอร์ชิ้นนั้น
- ไม่มีเฟอร์ใดเข้าถึงได้: NPC ทำท่าพัก มองรอบ ๆ หรือยืดตัวในจุดปลอดภัย
- เมื่อผู้เล่นย้ายหรือเก็บเฟอร์ที่เป็นเป้าหมายระหว่าง NPC เดินไป ให้ยกเลิกเป้าหมายเดิมและเลือกกิจกรรมใหม่
- เมื่อการจัดวางเปลี่ยน ต้องประเมินการเข้าถึงใหม่ เพื่อให้เฟอร์ที่กลับมาเดินถึงใช้ได้อีกครั้ง

## 4. การแจ้งเตือนเฟอร์ที่ใช้งานไม่ได้

- เฟอร์ที่ NPC เข้าใช้งานไม่ได้มีเครื่องหมายแจ้งเตือน
- แสดงชัดในโหมดตกแต่ง หรือเมื่อเลือกดูเฟอร์ ซ่อนเครื่องหมายระหว่างเล่นปกติเพื่อรักษาบรรยากาศ
- ตัวอย่างข้อความ: “ทางเข้าใช้งานถูกบังอยู่”
- การแจ้งเตือนนี้ไม่ห้ามผู้เล่นยืนยันวาง เพียงบอกผลว่า NPC จะไม่ใช้เฟอร์ชิ้นนั้น

## 5. เงื่อนไขผ่านการบูรณะและข้อห้าม

- เฟอร์บังคับที่วางครบแต่ NPC เดินไม่ถึง ยังนับว่าครบสำหรับผ่านการบูรณะ
- ผลของทางที่ถูกบังคือ NPC ไม่เล่นแอคชั่นกับเฟอร์นั้น การคราฟผ่าน UI ยังทำได้ตามเงื่อนไขบริการ
- ห้ามวางเฟอร์ทับตัว NPC หรือทำให้ตัวผู้เล่นซ้อนอยู่ในสิ่งกีดขวาง
- กันจุดเกิดและทางออกไว้ เพื่อให้เข้าและออกจากด่านได้
- ไม่บังคับให้ผู้เล่นรักษาทางเดินไปถึงเฟอร์ทุกชิ้น

## 6. รายละเอียดที่ยังไม่ได้กำหนด

- รายการและจำนวนเฟอร์บังคับของแต่ละด่าน
- มินิเกมปลดล็อคเป็นรายชิ้นหรือเป็นชุด และการปลดล็อคให้ตัวไอเทมหรือสิทธิ์ในการหา/สร้างเฟอร์
- รูปแบบภาพและระดับความยากของมินิเกมหมุนภาพ
- กิจกรรม ระยะเวลา และวิธีเลือกกิจกรรมของ NPC แต่ละตัว
- ขนาดช่องใช้งาน พื้นที่ปลอดภัย และวิธีจัดการสิ่งกีดขวางชั่วคราว เช่น ตัวละครอื่น

หัวข้อที่ยังไม่กำหนดเหล่านี้เป็นงานออกแบบต่อ ไม่ถือเป็นข้อตกลงที่พี่แยมยืนยันแล้ว

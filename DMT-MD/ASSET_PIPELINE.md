## Texture import มาตรฐานใหม่

| ค่า | ตั้งเป็น |
|---|---|
| Texture Type | Sprite 2D and UI สำหรับภาพ prop |
| Max Size | **256** |
| Resize Algorithm | **Mitchell** |
| Format | **Automatic** |
| Compression | **None / Uncompressed** |
| Mipmaps | ปิด |
| Alpha | โปร่งใสจริง และ alphaIsTransparency เปิด |
| Sprite mode / mesh | Single / Full Rect สำหรับภาพเดี่ยวที่ใช้ในรอบล่าสุด |
| Pivot | ใกล้ฐาน/เท้า กำหนดตามรูป |
| PPU | คำนวณตามขนาดเป้าหมายของชิ้นนั้น |

ข้อตกลงจากผู้ใช้คือ **ลดความละเอียด texture แต่ให้ขนาดที่เห็นในโลกเกมเท่าเดิม** ไม่ใช่ตั้ง PPU เท่ากันทุกชิ้น รูปขนาดใหญ่ที่มีอยู่ก่อนอาจถูกผู้ใช้ปรับไว้แล้ว จึงไม่แก้ทั้งโครงการรวดเดียวโดยไม่มีคำขอ

GDD เดิมมี baseline tile 256×192, PPU 128, pivot Y 0.17 ซึ่งเป็นสเปกของ tile ชุดนั้น ไม่ใช่ข้อบังคับให้ภาพร้าน/สัตว์/เฟอร์ทุกไฟล์ใช้ PPU 128 เหมือนกัน

ค่าตัวละครที่ใช้เป็นอ้างอิงจากรอบตรวจล่าสุดสูงประมาณ 1.5247 world units การจัดฉากจะตรวจระดับเคาน์เตอร์ ม้านั่ง พุ่มไม้ และความกว้างร้านเทียบตัวละครด้วย

ตัวอย่างค่าความกว้างที่เลือกในสวนผลไม้ (ส่วนภาพที่มีเนื้อหา ไม่รวมขอบโปร่งใส): ร้าน 4.2, แอปเปิ้ล 1.65, พุ่มเชอร์รี่ 1.3, ต้นสตรอเบอร์รี่ 1.5, โต๊ะคัดผลไม้ 1.7, รถเข็น 1.05, ชุดที่นั่ง 1.6 และลัง 0.8 world units

## ทำมุมให้ตรง Grid

วัตถุบนพื้นใช้สองแนวแกนเดียวกันทั้งฉาก: screen slope `+0.5` และ `−0.5` เสาตั้งตรง ไม่มีจุดรวมสายตาแบบ perspective

สำหรับรั้ว ขอบแปลง และทางเดินที่ต้องตรง cell เป๊ะ ให้ใช้ Mesh/Tilemap จากพิกัด Grid จริง ใช้ภาพหรือ texture เป็นผิว แปลงดินและขอบไม้แยก render ด้านหลัง/หน้าเพื่อให้พืชอยู่ในแปลงและถูกบังด้านหน้าได้

Native Mesh ที่ใส่ vertex color ในชุดที่ทำแล้วแปลงสีด้วย `.linear` เพื่อให้โทนที่แสดงสอดคล้องกับสีต้นทางในโครงการ อย่าปรับสีซ้ำกับ asset เดิมโดยไม่ตรวจ material/color space

พื้นทรายที่นำกลับมาใช้หลายด่านคือ `CornPath.prefab` ซึ่งปัจจุบันอ้าง Mesh/Material ทรายแล้ว แม้ชื่อยังเป็น CornPath ใช้สีจาก GardenPath atlas และ quad เต็ม cell ต่อกันเป็นผืน ไม่ใช่ PNG หญ้าทั้งช่อง 10×10

## สิ่งที่ตรวจเมื่อส่งงาน

- ภาพที่เห็นคือเวอร์ชันที่ผู้ใช้อนุมัติล่าสุด
- มีไฟล์ PNG ภายในโครงการ ไม่พึ่งไฟล์ใน generated_images อย่างเดียว
- รูปใหม่ตั้งค่า 256/Mitchell/Automatic/None และขนาดโลกไม่หด
- ตรวจไม้รั้ว ขอบแปลง พื้น สะพาน และฐานร้านเทียบเส้น Grid
- ทางเข้าต้องพอให้ตัวละครผ่าน และ footprint ไม่ปิดเส้นเดินหลัก
- เข้า Play Mode แล้วพิสูจน์ว่า frameCount เปลี่ยน จากนั้นตรวจ `CanStandAt` และ Console
- สร้าง Prefab ชิ้นเดี่ยวกับชุดรวม บันทึก Scene/Asset และคืนตำแหน่งกล้อง/ผู้เล่นที่ขยับชั่วคราวเพื่อถ่ายภาพ

# ข้อตกลงภาพและ layout สำหรับ Unity

อัปเดต: 26 ตุลาคม 2026 · เวลาอ้างอิง Asia/Bangkok

เอกสารนี้รวมสิ่งที่คุยและเลือกใช้ระหว่างสร้าง mockup ด่านตะวันออก เป็นรายละเอียดภาพต่อจาก `GAME_DESIGN.md` เดิม ไม่เปลี่ยนระบบเศรษฐกิจหรือบทบาทผู้เล่น

## ทิศทางร่วมทุกด่าน

- พื้นที่ด่าน 10×10 ตามช่องที่วางไว้ในแมพ เน้นร้าน/จุดทำงาน มีสวนหรือพื้นที่ผลิตตัวอย่างขนาดเล็กข้างร้าน
- สไตล์ 2D painted chibi เส้นขอบน้ำตาลเข้มหนา เรียบ อ่านง่าย สอดคล้องตัวละครสาวผมสีน้ำตาลหูกระต่าย ชุดแดง–ครีม
- สีตามภาพเกมจริง: สนามหญ้าเขียวมะกอก ทางเดินพีช/ทราย ไม้น้ำตาลส้ม ผนังครีม สีผลผลิตใช้เป็นจุดเน้น
- ลดความแน่นของต้นไม้/หญ้าและรายละเอียดใบ ใช้พุ่มดอกไม้พอประมาณ เพิ่มเฟอร์นิเจอร์ให้ตรงหน้าที่และธีมของแต่ละด่าน
- อาคารแต่ละด่านควรมีรูปทรงต่างกันได้ ไม่ใช้ร้านเดียวเปลี่ยนแค่ป้ายทุกด่าน
- แนวฐานร้าน รั้ว แปลง ทางเดิน สะพาน โต๊ะ และม้านั่งต้องขนานกับ **Grid Isometric 2:1 เดียวกันทั้งฉาก** เสาตั้งตรง ไม่มี perspective บิดออกนอกเส้น
- จัดรั้วที่ขอบนอกสุดของพื้นที่ ก่อนถึงทางเดินรอบด่าน เว้นทางเข้าที่ตัวละครผ่านได้
- เปิดพื้นที่เดินและอ่านสินค้าให้ชัด ป้ายใช้รูปผลผลิต และจัดเข้ากับคาน/ชายคาเมื่อวางบนร้าน

เรื่อง Max Size 256, PPU และการทำ Mesh อยู่ใน [ASSET_PIPELINE.md](/Users/yamujung/Desktop/Unity/InternalGame/DMT-MD/ASSET_PIPELINE.md) เพราะเป็นขั้นตอนเทคนิค

## ข้อตกลงรายด่านที่นำเข้าแล้ว

| ด่าน | ภาพ/layout ที่เลือกหรือแก้ |
|---|---|
| ฟาร์มแรก `farm_a` | ร้านขายแครอท ถุงข้าว และหอม มีแปลงเล็กข้างร้าน หลังคาหน้าจั่ว ป้ายสินค้า ขยายร้านและเพิ่มของ/เฟอร์ ลดไม้ประดับ ต่อมาจัดแปลงให้เท่ากันและตรง Grid |
| ป่าผืนแรก `forest_a` | ร้านท่อนไม้หลังคาเขียว รูปแบบต่างจากฟาร์มแรก มีเห็ด เบอร์รี่ และกองไม้ ป้ายเตี้ยข้างทางเดิน พื้น/ทางเดินแยกจากวัตถุ และเอาหญ้าที่ติดภาพพื้นออกตามคำขอ |
| โรงวัว–ไก่–ผึ้ง `animal_a` | ร้านหลังคาน้ำเงิน คอกวัว โรงไก่ รังผึ้ง เปลี่ยนต้นไม้ใหญ่บางจุดเป็นพุ่มไม้/ดอกไม้ |
| ไร่ผัก `farm_b` | ร้านแบบซุ้มไม้พร้อมของและเฟอร์มากขึ้น ลดขนาดแปลงมันฝรั่ง กะหล่ำปลี มะเขือเทศ และคุมโทนตามเกม |
| ป่าลึก `forest_b` | ร้านสมุนไพร/ดอกไม้/หิน หลังคาเขียวหม่น รั้วและขอบแปลงเป็นหิน พื้นหินและเฟอร์เหมาะกับธีม จัดแปลงเรียงตรงกัน เพิ่มมุมทำงาน |
| โรงแกะ–เป็ด–แพะ `animal_b` | คอกแกะ คอกแพะ บ่อเป็ด ร้านหลังคาสีน้ำตาล ป้ายสินค้าอยู่บนหลังคา/ชายคาและติดตั้งให้เข้ากับโครงร้าน |
| บ่อปลา `animal_fish` | บ่อปลา สะพานและร้านธีมประมง ปรับแนวรั้ว/สะพาน และทางเดินตามเส้น Grid |
| ไร่ข้าวโพด `farm_c` | ร้านแสดงข้าวโพด ฟักทอง บีทรูท กลับด้านร้านตามคำขอ เลื่อนแปลงไปซ้ายและเหลือแปลงหลัก 3 ชนิด ทางเดินเปลี่ยนเป็นทราย |
| โรงกระต่าย `animal_rabbit` | ร้านกระต่าย คอก/บ้านเล็กสองชุด กระต่าย 4 ตัว มุมดูแลและปุ๋ยอินทรีย์ ปรับของให้ไม่บังสัตว์มากเกินไป ใช้ทางเดินทราย |
| โรงผึ้ง `animal_bee` | ร้านหลังคาน้ำตาล ป้ายน้ำผึ้ง/ขี้ผึ้ง/ดอกไม้ รังผึ้ง 3 รังเท่ากัน แปลงดอกไม้เล็ก 2 แปลง โต๊ะเก็บน้ำผึ้งและมุมนั่งพัก |
| สวนผลไม้ `farm_d` | ร้านหลังคาแดง กันสาดแดง–ครีม ต้นแอปเปิ้ล 1 ต้น พุ่มเชอร์รี่เตี้ย 1 พุ่ม แปลงสตรอเบอร์รี่ โต๊ะคัดผลไม้ รถเข็น ลัง และที่นั่ง |

## ความสัมพันธ์กับเกมดีไซน์หลัก

GDD กำหนดให้ NPC ประจำด่านเป็นผู้ผลิตวัตถุดิบ ผู้เล่นเป็นผู้ประสานเมือง บูรณะ เก็บของ คราฟ และส่งเควส ดังนั้นแปลงในภาพเป็นส่วนของภาพด่านผลิต ไม่ได้เพิ่มกติกาให้ผู้เล่นต้องปลูกเอง

ร้านที่วาดใน passive stage เป็นภาพจุดบริการ/เก็บผลผลิต ยังไม่ได้อนุมัติเพิ่มระบบขายของจาก passive shop โดยตรง การตกแต่งเฟอร์ยังเป็น cosmetic ตาม GDD ไม่เพิ่มโบนัสผลผลิตเอง

โมเดลการบูรณะเดิมคือ ทำความสะอาด → ซ่อม → วางเฟอร์ → ไดอารี่/ปลดล็อค การมีฉากที่ตกแต่งเสร็จเป็นเป้าหมายภาพหลังบูรณะ ไม่ได้หมายความว่าวงจร 4 ขั้น implement ใน Unity แล้ว

ระบบ warp, แคตตาล็อกเฟอร์ ราคา unlock และกฎคลังให้ยึด GDD และข้อมูลที่ผู้ใช้อนุมัติ ไม่อนุมานเพิ่มจากภาพ

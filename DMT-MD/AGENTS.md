1. อ่านไฟล์เดิมและแก้เพิ่มเฉพาะส่วนที่เกี่ยวข้อง อย่าเขียนทับเอกสารเดิมทั้งหมด
2. แยกสถานะ HTML prototype, Unity mockup และ gameplay ที่ implement แล้วให้ชัด
3. ไม่ย้ายหรือเปลี่ยนดีไซน์/สมดุลเองเพียงเพราะกำลังเขียนเอกสาร
4. ไม่คัดลอก token, API key, รหัสผ่าน หรือ GitHub credential ลงเอกสาร
5. ใส่วันที่เป็น Asia/Bangkok และอ้างพาธจริง ผลตรวจจริง พร้อมขอบเขตที่ตรวจ
6. งานแต่ละรอบที่มีผลกับโปรเจกต์ให้อัปเดตไฟล์หัวข้อนั้นและ `WORK_LOG.md` ถ้ามีไฟล์ใหม่เพิ่มลิงก์ใน `README.md`
7. ไม่บันทึกคำว่าเสร็จครบวงจรจากการเห็นภาพหรือแค่เข้า Play Mode ต้องระบุว่าทดสอบอะไรผ่านจริง

`NongCoco-DMT/AGENTS.md` เดิมอธิบาย HTML prototype และมีตัวอย่างพาธ/เวอร์ชันจากช่วงก่อนหน้า อย่านำข้อห้ามเรื่อง bundler หรือรูปแบบไฟล์ HTML ไปเหมารวมเป็นข้อจำกัดของ Unity โดยอัตโนมัติ เอกสารใหม่ไม่ได้แทนที่ไฟล์เดิม

## ข้อตกลงที่ใช้กับ Asset

- ภาพใหม่และการวางของต้องตรง Grid Isometric 2:1 ของเกม
- เทียบขนาดกับตัวละครและพื้นที่ด่าน 10×10
- สร้างภาพตัวอย่างก่อน จากนั้นแยกและนำเข้าเมื่อผู้ใช้อนุมัติแบบแล้ว
- รูปใหม่: Max Size 256, Mitchell, Automatic, Compression None, ปิด mipmaps และคงขนาดในโลกเกม
- เรื่องระบบปรับสเกลอัตโนมัติทุกชิ้นพักไว้ตามคำขอผู้ใช้

ตอบผู้ใช้เป็นภาษาไทย กระชับ และส่งลิงก์ไฟล์ที่เปิดใช้งานได้

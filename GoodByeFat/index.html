เชื่อมต่อ Google Sheet

วิธีตั้งค่า Google Sheet ครั้งแรก

  1. เปิด Google Sheet ที่จะใช้เก็บข้อมูล → เมนู Extensions → Apps Script
  2. ลบโค้ดเดิมทั้งหมด แล้ววางโค้ดจากไฟล์ apps-script.gs
  3. เลือกฟังก์ชัน setup ที่แถบด้านบน แล้วกด ▶️ Run ครั้งเดียว
  4. กด Deploy → New deployment → Web app
  5. Execute as: Me, Who has access: Anyone → Deploy
  6. ก็อป URL ที่ได้มาวางในช่องด้านบน แล้วกดบันทึก

เว็บนี้ทำงานยังไง

ไม่มีการเรียก API ใดๆ และไม่ต้องใช้ API key — เว็บนี้แค่เตรียมคำสั่งให้พี่เอาไปวางในแอป Claude ที่พี่ใช้อยู่แล้ว แล้วแกะคำตอบที่ได้กลับมาใส่ฟอร์มให้อัตโนมัติ

ทั้งหน้าเป็นไฟล์เดียวจบ ไม่โหลดอะไรจากอินเทอร์เน็ต จะเปิดแบบออฟไลน์ก็ได้ (ยกเว้นตอนกดบันทึก/ดูประวัติ ที่ต้องต่อ Google Sheet)
